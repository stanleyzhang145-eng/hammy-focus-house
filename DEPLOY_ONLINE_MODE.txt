HAMMY FOCUS HOUSE V20 — ONLINE AND CLOUD DEPLOYMENT

This file replaces the older JSON-file deployment instructions.

The v20 server does NOT save profiles in server-data/profiles.json.
All long-term data is stored in PostgreSQL through DATABASE_URL.

START HERE
Read:
RENDER_POSTGRES_SETUP.txt

REQUIRED GITHUB FILES
- index.html
- premium.js and premium.css
- cloud.js and cloud.css
- online.js and online.css
- gallery.js
- server.js
- db.js
- schema.sql
- package.json
- admin.html, admin.js, admin.css
- service-worker.js
- manifest and icon files

RENDER WEB SERVICE
Build command:
npm install

Start command:
npm start

REQUIRED ENVIRONMENT VARIABLES
DATABASE_URL = Render PostgreSQL connection URL
ADMIN_KEY = long private random value
ALLOW_PREMIUM_PREVIEW = true while testing the current Premium preview

VERIFY
Open /api/health and confirm:
- version: 20
- databaseReady: true
- databaseMode: postgres

The game remains playable offline, but accounts, gallery publishing,
reactions, reports, blocking, and cloud sync require the server and database.
