HAMMY FOCUS HOUSE V22 — TOP SECRET ADMIN

HOW TO OPEN
1. Open Account.
2. Tap the Build v22 badge seven times.
3. Enter the private ADMIN_ACCESS_CODE.
4. The moderation panel opens.

SECURITY
- ADMIN_ACCESS_CODE exists only in the Render server environment.
- It is not included in the GitHub files.
- Admin sessions expire after 30 minutes.
- Five incorrect attempts lock login for 15 minutes.
- The session token is signed by the server.
- Editing the website does not create a valid admin session.

IMPORTANT
There cannot be a truly secret fixed code inside a public GitHub repository.
Anyone could read it. This build therefore generates and checks the code
server-side.
